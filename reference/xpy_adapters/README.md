# xpy reference adapters

These are the reference adapter implementations from
`/storage/yuhongtaoLab/linpeiran/xpy/lab/baseline/benchmark/src/adapters/`.
They are included to document how the benchmark adapters were constructed and
which upstream hooks / monkey-patches were used. They are reference code, not
the current package's runnable adapters.

Historical note: some xpy paths assume the original 50-PC MERFISH dataset. The
current v1 package explicitly does not use 50-PC features.
