# Spa3D (blocked)

Spa3D is blocked for this benchmark.

Reasons:

- it outputs spatial domains, not a gene-expression decoder;
- it cannot produce the 1,122-gene target expression matrix required by the
  fixed-coordinate task;
- dense neighbor construction is not feasible at the tested scale.

No predictions are reported. This method should be discussed as a domain-only
method, not as an expression reconstruction baseline.
